navegáveis por âncoras: Sobre mim, Formação, Portfólio e Contato.

## Estrutura
```
index.html
css/style.css
js/script.js
```

## Como publicar no GitHub Pages

1. Crie um repositório **público** no GitHub chamado `portfolio-cristian-dias` (ou o nome que preferir, desde que contenha seu nome).
2. Envie estes três arquivos (mantendo a estrutura de pastas `css/` e `js/`):
   ```
   git init
   git add .
   git commit -m "Portfólio inicial"
   git branch -M main
   git remote add origin https://github.com/SEU-USUARIO-GITHUB/portfolio-cristian-dias.git
   git push -u origin main
   ```
   > Troque `SEU-USUARIO-GITHUB` pelo seu nome de usuário do GitHub (não é o e-mail —
   > é o `github.com/assim-que-aparece-na-sua-conta`). Se ainda não tem conta,
   > crie em github.com/signup; o e-mail `cristiandias870@gmail.com` pode ser usado
   > pra cadastrar, mas o usuário é escolhido separadamente.
3. No GitHub, vá em **Settings → Pages**.
4. Em "Branch", selecione `main` e a pasta `/root`, depois clique em **Save**.
5. Em alguns minutos o site estará disponível em:
   `https://SEU-USUARIO-GITHUB.github.io/portfolio-cristian-dias/`

## Antes de entregar
- Confira se o link do site contém seu nome (renomeie o repositório se precisar).
- Teste o formulário de contato e os dois temas (claro/escuro).
- Tire os prints de cada seção com o site já publicado (não use localhost).
- Cole o link do site e do repositório no relatório da atividade.
